### 2.3 자동 저장 기능

#### 테스트 시나리오 7: 자동 저장 동작

**전제 조건**:
- Feature Flag `newBoardsEditor` 활성화
- 에디터가 로드되고 편집 가능 상태

**테스트 단계**:
1. 에디터에서 텍스트 입력
2. 2초 대기 (Debounce 시간)
3. 저장 상태 표시 확인
4. 서버에 저장 확인

**예상 결과**:
- ✅ 편집 후 2초 후 자동 저장 시작
- ✅ "Saving..." 상태 표시
- ✅ 저장 완료 후 "Saved" 상태 표시
- ✅ 3초 후 상태 표시 제거
- ✅ 서버에 JSON 스냅샷 저장됨
