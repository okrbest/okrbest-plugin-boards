## Bug 3: i18n "edit" -> "view" 불일치 - 이미 수정됨

`git diff main`으로 확인한 결과, i18n 수정은 **이미 작업 트리에 적용**되어 있습니다:

- EN: "will be able to **edit** it" -> "will be able to **view** it" (4개 키 모두)
- KO: "**편집**할 수 있습니다" -> "**열람**할 수 있습니다" (4개 키 모두)
- "An admin can change this default permission afterwards" 문구 추가됨

**Permission gate 변경** (`ManageBoardRoles` -> `ManageBoardType`): [`webapp/src/hooks/permissions.tsx`](webapp/src/hooks/permissions.tsx) 21-22줄에서 두 permission 모두 `'canManageBoard'` capability로 매핑되므로 기능적으로 동일합니다. 채널 최소 역할 변경은 개별 멤버 역할 관리가 아닌 보드 설정 변경이므로 `ManageBoardType`이 의미적으로 더 적합합니다.

**추가 작업 불필요** - 현재 상태가 올바릅니다.

## Bug 4: has_acl_entries boardFields 누락 - 버그 아님

`has_acl_entries` 컬럼은 **비정규화된 인덱스 최적화 컬럼**으로, Board 모델 필드가 아닌 설계입니다:

- **쓰기**: `insertBoard`에서 `boardHasACLEntries(board.Properties)`로 매 쓰기 시 정확히 재계산 (382줄, 400줄, 421줄)
- **읽기 필터**: `getBoardsInTeam` (284줄), `getBoardsInUserTeams` (314줄)에서 WHERE 조건으로 사용 중
- **모델**: `Board` 구조체에 해당 필드가 없으므로 `boardFields`/`boardsFromRows`에 포함할 필요 없음

컬럼은 매 `PatchBoard` -> `insertBoard` 호출 시 Properties에서 재계산되므로 stale 데이터 문제가 발생하지 않습니다. 의도대로 동작 중이며 수정 불필요합니다.
