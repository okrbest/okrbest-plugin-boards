# Contract: 화면 표면

**Spec**: [spec.md](../spec.md) | FR-012·FR-013·FR-014

화면은 서버가 거절할 조작을 사용자에게 내밀지 않는다. 서버가 진실이고 화면은 같은 답을
한다 — 화면만 고치는 것은 이 기능이 아니다.

## 표면과 기대

| ID | 표면 | 잠금 꺼짐 | 잠금 켜짐 · 에디터 | 잠금 켜짐 · 보드 관리자 |
|---|---|---|---|---|
| U-01 | 표 헤더 메뉴의 속성 추가·삭제 | 지금 그대로 | 없음 | 있음 |
| U-02 | 카드 상세의 속성 추가 진입점 | 지금 그대로 | 없음 | 있음 |
| U-03 | 카드 상세의 속성별 이름·유형 변경, 삭제 | 지금 그대로 | 없음 | 있음 |
| U-04 | select 값 입력의 옵션 만들기·이름·색·순서·삭제 | 지금 그대로 | 없음 | 있음 |
| U-05 | multiselect 값 입력의 같은 조작 | 지금 그대로 | 없음 | 있음 |
| U-06 | 칸반 열 추가 | 지금 그대로 | 없음 | 있음 |
| U-07 | 칸반 열 이름·색·삭제 | 지금 그대로 | 없음 | 있음 |
| U-08 | select·multiselect에서 **값 고르기·비우기** | 지금 그대로 | **있음** | 있음 |
| U-09 | 공유 위젯의 잠금 토글 섹션 | 에디터에겐 없음 | 없음 | 있음 |

U-08이 FR-013이다. 잠금은 보드가 무엇을 기록하는지를 잠그지, 카드를 채우는 일을 잠그지
않는다.

## 잠금 상태를 아직 모를 때

화면이 보드 설정을 읽기 전이라면 잠기지 않은 것으로 본다. 잠금은 값이 있을 때만 켜지고
(FR-002·FR-003), 서버가 어차피 최종 판정을 하므로 화면이 성급히 감출 이유가 없다.

## i18n

토글 섹션의 제목과 설명 문자열을 `webapp/i18n/en.json`과 `webapp/i18n/ko.json`에 같은
변경으로 추가한다(헌법 원칙 V). 기존 `OkrBoard.title`·`OkrBoard.description` 쌍이 선례다.
