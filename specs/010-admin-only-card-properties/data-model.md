# Data Model: 속성 편집을 관리자에게만 열지 보드가 정한다

**Spec**: [spec.md](./spec.md) | **Research**: [research.md](./research.md)

## 속성 편집 잠금

보드가 기억하는 켜짐/꺼짐 하나.

| 항목 | 값 |
|---|---|
| 사는 곳 | `board.properties` (`propertyAccess`·`okrBoard`·`orgColors`와 같은 자리) |
| 키 | `adminOnlyCardProperties` |
| 형 | boolean |
| 기본 | 없음 = 꺼짐 |

### 읽기 규칙

값이 boolean `true`일 때만 잠김이다. 그 밖은 전부 꺼짐으로 읽는다 — 키가 없을 때,
`false`일 때, 그리고 문자열·숫자·개체처럼 boolean이 아닐 때(FR-003).

`board.properties`는 다른 기능도 함께 쓰는 자유 형식 JSON이다. 반쯤 이해한 값을
"잠김"으로 읽으면 아무도 잠그지 않은 보드에서 속성 편집이 사라진다. `okrBoardSettings`가
망가진 값을 "꺼짐"으로 읽는 것과 같은 규율이다.

### 쓰기 규칙

이 키를 쓰거나 지우는 패치는 Manage 등급을 요구한다(FR-009). 스위치를 제한 대상이
스스로 끌 수 있으면 잠금이 아니다.

### 마이그레이션

없다. 기존 보드는 키가 없는 상태로 남고 그것이 곧 꺼짐이다(R8).

## 상태 전이

```
(값 없음) ──관리자가 켠다──▶ true ──관리자가 끈다──▶ false
    │                                                   │
    └───────────── 둘 다 "꺼짐"으로 읽힌다 ◀─────────────┘
```

전이는 보드 패치 한 번이고, 다른 보드 설정 변경과 같은 방식으로 참여자에게 전달된다.

## 판정에 쓰이는 기존 개념

이 기능이 새로 만들지 않고 읽기만 하는 것들.

| 개념 | 어디서 오나 | 이 기능에서의 쓰임 |
|---|---|---|
| 보드 유효 권한 등급 | 보드 멤버십 + 팀 권한 | Manage 등급인지 판정 |
| 카드 속성 목록 | `board.cardProperties` | 패치가 이것을 건드리는지 판정 |
