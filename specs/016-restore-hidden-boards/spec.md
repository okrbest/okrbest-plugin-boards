# Feature Specification: 숨긴 보드를 사이드바에서 되찾는다

**Feature Branch**: `016-restore-hidden-boards`

**Created**: 2026-09-23

**Status**: Draft

**Input**: User description: "숨긴 보드 복구 UI. 사이드바 각 카테고리의 보드 목록 아래에 "숨긴 보드 {count}개" 접힘 행을 둔다(숨긴 보드가 0개면 표시 안 함, 카테고리가 접혀 있으면 표시 안 함, 기본 접힘). 펼치면 숨긴 보드를 흐린 행으로 나열하고, 행에 마우스를 올리면 "다시 표시" 버튼, 헤더 오른쪽에 "모두 표시" 버튼. 보드 숨기기 직후 "'{제목}' 보드를 숨겼습니다 · 실행 취소" 알림을 띄우고 실행 취소를 누르면 되돌린다. 보이는 보드가 0개인데 숨긴 보드가 있는 카테고리는 "보드가 존재하지 않음" 대신 접힘 행만 보여준다. 배경: 지금은 숨긴 보드를 복구하는 UI가 없고, "보드 찾기"로 이름을 검색해 열어야만 자동 복구가 동작한다."

## 왜 지금이 문제인가

사이드바에서 보드를 숨기는 데는 클릭 한 번이면 된다. 확인도 없고 되돌리기도 없다.

숨긴 보드를 되찾는 자리는 없다. 이름을 기억해 "보드 찾기"로 검색해 열어야만 보드가
다시 사이드바에 나타난다. 이름을 잊으면 숨겼다는 사실조차 알 길이 없다.

카테고리의 보드를 전부 숨기면 "해당 카테고리에 보드가 존재하지 않음"이 나온다. 보드가
지워졌거나 권한을 잃었다고 오해하기 쉽다.

## 숨김은 나에게만 적용된다

보드 숨김은 내 사이드바에서 그 보드를 치우는 개인 설정이다. 다른 사람의 사이드바, 보드
자체, 보드 멤버십에는 아무 영향이 없다. 되찾기도 같은 원칙이다. 내가 되찾으면 내
사이드바에만 돌아온다.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 숨긴 보드를 그 자리에서 되찾는다 (Priority: P1) 🎯 MVP

카테고리를 펼치면 보드 목록 아래에 "숨긴 보드 2개" 같은 흐린 행이 하나 있다. 누르면
숨긴 보드들이 흐린 글씨와 숨김 표시로 나열된다. 되찾고 싶은 보드 위에 마우스를 올려
"다시 표시"를 누르면 그 보드가 곧바로 카테고리의 제 자리로 돌아온다.

**Why this priority**: 이 기능의 전부다. 숨긴 보드가 어디 있는지 보이고, 거기서 바로
되찾을 수 있으면 나머지는 편의다.

**Independent Test**: 보드 하나를 숨긴 뒤 카테고리 아래 행을 펼쳐 "다시 표시"를 누르면
보드가 목록에 돌아오고 행이 사라진다.

**Acceptance Scenarios**:

1. **Given** 숨긴 보드가 2개인 카테고리, **When** 카테고리를 펼쳐 보면, **Then** 보드 목록 아래에 "숨긴 보드 2개" 행이 있다
2. **Given** 그 행, **When** 누르면, **Then** 숨긴 보드 2개가 아이콘·제목과 숨김 표시로 흐리게 나열된다
3. **Given** 펼친 목록, **When** 보드 하나의 "다시 표시"를 누르면, **Then** 그 보드가 카테고리 안 원래 순서 자리로 돌아오고 행의 수가 1로 준다
4. **Given** 숨긴 보드가 마지막 하나인 상태, **When** 그 보드를 되찾으면, **Then** 행 자체가 사라진다
5. **Given** 숨긴 보드가 없는 카테고리, **When** 펼쳐 보면, **Then** 행이 없다
6. **Given** 접힌 카테고리, **When** 그대로 보면, **Then** 행이 보이지 않는다
7. **Given** 펼친 목록, **When** 되찾기가 실패하면(서버 거절, 네트워크 끊김), **Then** 보드는 숨긴 목록에 남고 실패했다는 알림이 뜬다
8. **Given** 펼친 목록, **When** 다른 카테고리로 시선을 옮겼다가 돌아와도, **Then** 펼침 상태는 그 카테고리에서 유지된다. 페이지를 새로 열면 다시 접힌다

### User Story 2 - 잘못 숨긴 직후 되돌린다 (Priority: P1)

보드를 숨기면 화면 아래에 "'FY27 OKR' 보드를 숨겼습니다"와 "실행 취소"가 잠시 뜬다.
잘못 눌렀다면 "실행 취소"로 그 자리에서 되돌린다.

**Why this priority**: 숨기기는 클릭 한 번이라 실수가 잦다. 실수 직후가 되돌리기 가장
싼 순간이고, US1의 행을 찾아갈 필요조차 없앤다.

**Independent Test**: 보드를 숨긴 직후 "실행 취소"를 누르면 보드가 제자리로 돌아오고
알림이 사라진다.

**Acceptance Scenarios**:

1. **Given** 사이드바의 보드, **When** 숨기면, **Then** 화면 아래에 보드 제목이 든 안내와 "실행 취소"가 뜬다
2. **Given** 그 알림, **When** "실행 취소"를 누르면, **Then** 보드가 원래 자리로 돌아오고 알림이 사라진다
3. **Given** 그 알림, **When** 아무것도 하지 않으면, **Then** 알림은 사라지고 보드는 숨김 상태로 남는다. US1의 행에서 되찾을 수 있다
4. **Given** 보드 두 개를 연달아 숨김, **When** 알림을 보면, **Then** 마지막 보드의 알림만 보인다. 앞의 보드는 US1의 행에서 되찾는다
5. **Given** 지금 보고 있던 보드를 숨김, **When** 화면이 다른 보드로 옮겨진 뒤 "실행 취소"를 누르면, **Then** 숨겼던 보드가 사이드바에 돌아온다. 화면을 그 보드로 다시 옮기지는 않는다
6. **Given** 그 알림, **When** "실행 취소"가 실패하면, **Then** 보드는 숨김 상태로 남고 실패했다는 알림이 뜬다

### User Story 3 - 전부 숨긴 카테고리가 이유를 말한다 (Priority: P2)

카테고리의 보드를 모두 숨기면 "보드가 존재하지 않음" 대신 "숨긴 보드 3개" 행이 보인다.
보드가 사라진 것이 아니라 내가 숨겼다는 것을 바로 안다.

**Why this priority**: 오해를 막는 문구 교체다. US1이 있으면 자연히 따라오지만, 빠지면
"보드가 없음"과 "숨긴 보드 N개"가 나란히 떠서 서로 모순된다.

**Independent Test**: 카테고리의 보드를 전부 숨긴 뒤 펼쳐 보면 "보드가 존재하지 않음"
문구가 없고 숨긴 보드 행만 있다.

**Acceptance Scenarios**:

1. **Given** 보드가 전부 숨김인 카테고리, **When** 펼쳐 보면, **Then** "보드가 존재하지 않음" 문구는 없고 "숨긴 보드 N개" 행만 있다
2. **Given** 보드가 실제로 하나도 없는 카테고리, **When** 펼쳐 보면, **Then** 지금처럼 "보드가 존재하지 않음"이 보인다
3. **Given** 방금 만든 빈 카테고리, **When** 펼쳐 보면, **Then** 지금처럼 끌어다 놓기 안내가 보인다

### User Story 4 - 한 번에 모두 되찾는다 (Priority: P3)

숨긴 보드가 여럿이면 행 오른쪽의 "모두 표시"로 한 번에 되찾는다.

**Why this priority**: 숨긴 보드는 보통 한둘이라 US1로 충분하다. 여럿일 때 클릭을
줄이는 편의다.

**Independent Test**: 보드 3개를 숨긴 뒤 "모두 표시"를 누르면 셋 다 돌아오고 행이
사라진다.

**Acceptance Scenarios**:

1. **Given** 숨긴 보드 3개, **When** "모두 표시"를 누르면, **Then** 셋 다 원래 자리로 돌아오고 행이 사라진다
2. **Given** 숨긴 보드 3개, **When** "모두 표시" 중 하나가 실패하면, **Then** 성공한 보드는 돌아오고 실패한 보드는 행에 남으며 실패했다는 알림이 뜬다

### Edge Cases

- 숨긴 보드가 그사이 지워졌거나 내가 볼 권한을 잃었으면 숨긴 보드로 세지 않는다. 볼 수
  없는 보드는 되찾을 수도 없다.
- 다른 탭이나 기기에서 같은 보드를 되찾으면 이 화면의 행도 따라 줄어든다. 지금 사이드바가
  다른 변경을 받아들이는 길과 같다.
- 되찾은 보드는 카테고리 안 원래 순서로 돌아온다. 숨김은 순서를 바꾸지 않는다.
- 숨긴 보드는 끌어서 옮길 수 없다. 숨긴 보드 행은 보드 순서 바꾸기와 카테고리 간 이동에
  끼어들지 않는다. 보이는 보드를 끌어 놓는 위치 계산은 숨긴 보드 수와 무관하다.
- 템플릿은 사이드바에 원래 나오지 않으므로 숨긴 보드로도 세지 않는다.
- 카테고리를 끌어 옮기는 동안(카테고리 전체가 접히는 동안)에는 행도 함께 숨는다.
- 실행 취소 알림이 보이는 동안이면 사이드바가 있는 어느 화면에서든 "실행 취소"가
  작동한다.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 카테고리마다, 그 카테고리에서 내가 숨긴 보드 중 지금 볼 수 있는 보드의 수를 "숨긴 보드 N개" 행으로 보여준다. 수가 0이면 행을 두지 않는다.
- **FR-002**: 행은 카테고리가 펼쳐져 있을 때만, 보드 목록 바로 아래에 둔다.
- **FR-003**: 행은 기본 접힘이다. 누르면 펼쳐지고 다시 누르면 접힌다. 펼침 상태는 카테고리마다 따로 두고 페이지를 새로 열면 접힌 상태로 돌아간다.
- **FR-004**: 펼친 행은 숨긴 보드를 카테고리 안 순서대로 나열한다. 각 항목은 보드 아이콘·제목·숨김 표시를 흐리게 보여주고, 보이는 보드와 한눈에 구별된다.
- **FR-005**: 숨긴 보드 항목에는 "다시 표시" 동작이 있다. 누르면 그 보드가 내 사이드바에서 숨김 해제되어 카테고리 안 원래 순서 자리에 나타난다.
- **FR-006**: 펼친 행에 숨긴 보드가 2개 이상이면 "모두 표시" 동작이 있다. 누르면 그 카테고리의 숨긴 보드를 모두 숨김 해제한다. 숨긴 보드가 1개뿐이면 "다시 표시"만 둔다.
- **FR-007**: 숨김 해제가 실패하면 해당 보드는 숨긴 목록에 그대로 남고, 실패했다는 알림을 보여준다. 여러 보드 중 일부만 실패하면 성공한 보드만 돌아온다.
- **FR-008**: 보드를 숨기면 곧바로 화면 아래에 보드 제목이 든 안내와 "실행 취소"를 보여준다. 이 알림은 누를 시간이 충분하도록 최소 5초 동안 온전히 보인다(사라지는 애니메이션 시간은 빼고 센다).
- **FR-009**: "실행 취소"를 누르면 그 보드를 숨김 해제하고 알림을 닫는다. 화면을 그 보드로 옮기지는 않는다.
- **FR-010**: 알림은 한 번에 하나만 보여준다. 새 보드를 숨기면 앞의 알림을 새 알림으로 바꾼다.
- **FR-011**: 보이는 보드가 없고 숨긴 보드가 있는 카테고리에는 "보드가 존재하지 않음" 문구를 내지 않고 숨긴 보드 행만 보여준다. 보드가 실제로 없는 카테고리와 새로 만든 빈 카테고리의 표시는 바꾸지 않는다.
- **FR-012**: 숨긴 보드 항목은 끌어 옮길 수 없고, 보이는 보드의 순서 바꾸기·카테고리 간 이동에 영향을 주지 않는다.
- **FR-013**: 숨김 해제는 내 사이드바에만 적용된다. 다른 사람의 사이드바, 보드, 멤버십은 바꾸지 않는다.
- **FR-014**: 숨김 해제된 결과는 페이지를 새로 열어도 유지되고, 같은 계정의 다른 탭·기기에도 반영된다.
- **FR-015**: 이 기능이 보여주는 모든 문구는 한국어와 영어 두 로케일에서 제공한다.

### Key Entities

- **숨긴 보드**: 카테고리 안에서 내가 숨김으로 표시한 보드. 카테고리·순서는 그대로
  가진 채 사이드바에서만 치워진 상태다. 숨김 해제하면 같은 자리로 돌아온다.
- **숨김 알림**: 방금 숨긴 보드 하나를 가리키는 되돌리기 안내. 한 번에 하나만 있고 잠시
  뒤 사라진다.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 숨긴 보드가 있는 사용자는 검색이나 보드 이름 없이, 사이드바 안에서 클릭 두 번(행 펼치기, 다시 표시)으로 보드를 되찾는다.
- **SC-002**: 잘못 숨긴 보드를 숨긴 직후 클릭 한 번으로 되돌린다.
- **SC-003**: 보드를 전부 숨긴 카테고리를 보는 사용자가 "보드가 없다"로 오해할 문구를 보지 않는다.
- **SC-004**: 숨김 해제된 보드는 100% 카테고리 안 원래 순서 자리로 돌아온다.
- **SC-005**: 이 기능을 넣은 뒤에도 보이는 보드의 끌어 놓기 결과는 숨긴 보드 수와 무관하게 이전과 같다.
- **SC-006**: 숨김 해제가 실패한 경우 사용자는 100% 실패 사실을 알림으로 본다. 조용히 사라지는 실패는 없다.

## Assumptions

- 숨김 해제는 지금 "보드 찾기"로 열 때 자동으로 일어나는 것과 같은 동작이다. 서버 쪽에
  새로 만들 것은 없다.
- 숨긴 보드의 목록과 순서는 지금 사이드바가 이미 갖고 있는 카테고리 정보에서 얻는다.
  별도 저장이 필요 없다.
- 지금 화면 아래 알림은 2초 뒤 사라진다. 실행 취소를 누를 시간이 부족하므로 이 알림만
  더 오래 유지하거나 알림 전체 시간을 늘린다. 어느 쪽인지는 계획 단계가 정한다.
- 흐린 항목, 숨김 표시, 행의 모양은 사이드바가 이미 쓰는 시각 언어(보드 항목, 접힘
  아이콘, 흐린 보조 문구)를 그대로 쓴다. 새 시각 요소를 도입하지 않는다.
- 숨긴 보드가 여럿일 때 "모두 표시"는 보드마다 차례로 숨김 해제한다. 원자적 일괄 처리는
  요구하지 않는다.

## 범위 밖
