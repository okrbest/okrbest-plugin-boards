# Contract: 화면 표면 U-01~U-10

**Spec**: [spec.md](../spec.md) | **Plan**: [plan.md](../plan.md)

각 항목은 테스트 하나에 대응한다. "그린다"는 DOM에 있다, "없다"는 DOM에 없다는 뜻이다.

## 접힘 행 (`hiddenBoardsRow.tsx`, `sidebarCategory.tsx`)

| ID | Given | Then | 근거 |
|---|---|---|---|
| U-01 | 카테고리 펼침, 숨긴 보드 2개(스토어에 있음) | 보드 목록 아래에 `숨긴 보드 2개` 행을 그린다. Draggable이 아니다 | FR-001·002 |
| U-01a | 숨긴 보드 0개 | 행이 없다 | FR-001 |
| U-01b | 카테고리 접힘, 또는 카테고리 끌기 중(`forceCollapse`/`draggedItemID`) | 행이 없다 | FR-002, 경계 |
| U-01c | 숨긴 보드 중 하나가 스토어에 없다(지워짐·권한 상실) | 수에 세지 않고 항목도 없다 | 경계 |
| U-02 | U-01 상태 | 행은 접힘. 헤더를 누르면 항목 2개가 펼쳐지고, 다시 누르면 접힌다. 다시 그려도(다른 prop 변경) 펼침 상태가 유지된다 | FR-003 |
| U-03 | 펼침 | 항목은 메타데이터 순서. 각 항목에 보드 아이콘·제목·`HideIcon`이 있고 `octo-sidebar-item subitem` 흐린 스타일이다. 항목을 눌러도 보드로 이동하지 않는다 | FR-004 |
| U-04 | 펼침 | 각 항목에 접근 가능한 이름 `다시 표시`인 버튼이 있다(hover/focus 때 보임). 누르면 F-01을 그 보드로 부른다 | FR-005 |
| U-05 | 펼침, 숨긴 보드 2개 이상 | 헤더에 `모두 표시` 버튼. 누르면 F-01을 항목 순서대로 부른다 | FR-006 |
| U-06 | 보이는 보드 0개, 숨긴 보드 1개 이상 | `Sidebar.no-boards-in-category` 문구가 없고 행만 있다. 보이는 보드 0개·숨긴 보드 0개면 지금처럼 문구가 있다. 새 카테고리(`isNew`)는 끌어다 놓기 안내 그대로 | FR-011 |

## 숨기기 알림 (`sidebarBoardItem.tsx`, `flashMessages.tsx`)

| ID | Given | Then | 근거 |
|---|---|---|---|
| U-07 | 보드 항목 메뉴에서 `보드 숨기기` | 숨김 처리 뒤 `'{title}' 보드를 숨겼습니다` 알림이 뜨고 `실행 취소` 버튼이 있다. 5초 뒤 사라진다. 그 전에 다른 보드를 숨기면 새 알림으로 바뀐다 | FR-008·010 |
| U-08 | U-07 알림 | `실행 취소`를 누르면 F-01을 그 보드로 부르고 알림이 닫힌다. 화면 경로는 바뀌지 않는다 | FR-009 |
| U-09 | F-01이 실패 | `보드를 다시 표시하지 못했습니다` 알림(high). 스토어의 `hidden`은 그대로 참 | FR-007, SC-006 |
